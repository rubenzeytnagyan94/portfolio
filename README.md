# Ancient Pontos Fullstack Portfolio

## Run
1. `npm install`
2. Terminal 1: `npm run server`
3. Terminal 2: `npm run dev`
4. Open the Vite address shown in terminal (usually http://localhost:5173)

## Stack
React + JavaScript + CSS + Node.js + Express.

The contact form sends data to the Node/Express API and stores messages in `server/messages.json`.

Replace the demo email/GitHub text and project data in `src/main.jsx` with your own information.
